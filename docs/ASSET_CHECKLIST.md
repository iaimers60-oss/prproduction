# PR Production — Launch Asset Checklist

Nothing below has been invented on the website. Until you add each item, the site either hides
the related section or shows a clearly labelled placeholder.

## Brand
- [ ] Logo — transparent PNG or SVG-exported PNG, at least 600 px wide (Admin → Settings → Logo)
- [ ] Confirm tagline, brand statement, and location statement (Admin → Settings → Brand)

## Contact details (all optional, all hidden until added)
- [ ] Business WhatsApp number with country code, e.g. +91 9xxxx xxxxx (powers every WhatsApp button)
- [ ] Business email address
- [ ] Instagram profile URL
- [ ] YouTube channel URL
- [ ] Business address (only if you want it public)
- [ ] Cities you are ready to serve (e.g. Raipur, Bilaspur, Durg, Bhilai, Nagpur, Pune, Mumbai, Bhubaneswar, Cuttack)

## Homepage media
- [ ] Hero photograph — landscape, ≥ 2400 px wide, your strongest wedding image
- [ ] Hero video (optional) — 10–20 s, muted, H.264 .mp4, under ~8 MB, hosted on Supabase Storage or a CDN
- [ ] Introduction photograph — portrait orientation (team, behind the scenes, or a signature frame)

## Portfolio (per project)
- [ ] Project title, category, location, optional event date
- [ ] 2–3 sentence description
- [ ] Cover image (≥ 1600 px on the long edge)
- [ ] 8–30 gallery images (web-sized, ~2000 px long edge, JPG/WebP, under ~1 MB each)
- [ ] Google Drive folder link for the full gallery (only if the client agrees it can be public)
- [ ] Film link (YouTube/Vimeo) for projects with a film, plus film type
- [ ] Client permission to publish the photos

Aim for at least 6 real projects across Wedding, Pre-Wedding, and one other category before launch.
Mark 4–5 of the best as ★ Featured.

## Films
- [ ] Wedding highlight film link
- [ ] Pre-wedding film link
- [ ] Event film link
- [ ] Brand film link

## Testimonials (optional)
- [ ] Real client reviews with written permission to publish (name, event type, review, optional approved photo)

## Payments
- [ ] Account holder name (must match the bank account)
- [ ] Official UPI ID
- [ ] Official UPI QR code image, downloaded from your bank/UPI app (never a self-generated one)
- [ ] Bank name, account number, IFSC (optional)
- [ ] Payment instructions text (advance policy, what to send after paying)
- [ ] Razorpay account with KYC completed (only if you want online card/net-banking payments)

## Legal
- [ ] Review and personalise the Privacy Policy and Terms and Conditions pages, and set the "Last updated" date
- [ ] Confirm drone operations comply with current DGCA / Digital Sky rules before offering them

## Technical
- [ ] Domain name
- [ ] Supabase project created, migration run, admin user created
- [ ] Vercel project created with environment variables
